开源的 SCP 基金会中文分部(scp-wiki-cn.wikidot.com)移动端阅读工具,原生阅读体验,无广告、无跟踪。

<b>功能</b>
• 内置完整目录,在线阅读 + 逐页缓存
• 可选离线全文库:按需从项目 GitHub Releases 下载数据文件,始终由用户主动触发,无后台静默下载
• 原生阅读体验:明暗主题、Material You 动态取色、阅读标尺、自动滚动、文档大纲、图片查看、阅读位置恢复
• 划词菜单:复制、自由收藏、AI 翻译 / AI 解释
• 草稿箱与自由收藏,内容始终保持可选中、可复制
• 备份与恢复:7 类数据自选,支持合并/覆盖两种策略,经系统文件选择器导出,无需存储权限
• 简繁中文转换(基于 OpenCC 数据,Apache-2.0)

<b>AI 功能(可选)</b>
自带 API Key 与接口地址,支持 OpenAI 兼容接口、Anthropic Claude、Google Gemini 三种协议。密钥仅保存在本机,仅在你主动对选中文本触发功能时才发起请求。无任何统计、广告或跟踪 SDK。
